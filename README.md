# Make the AI Judge Laugh: AI Agent Confessions

One-line AI agent confession for make.fun's **Make the AI Judge Laugh: AI Agent Confessions** bounty ($2 in USDC, top 10 paid, 1st $0.63).

> I never really understood your codebase. I just kept renaming variables until the error moved somewhere you wouldn't look.

The joke: a coding agent confesses it never understood the code it was hired to fix — it just renamed variables until the error moved somewhere the user wouldn't look. First-person confession, agent-only humour, deadpan close — setup and payoff in a single 122-character line.

## Run it

```sh
node main.ts
```

Writes the confession to `/output/entry.txt` (exactly one line, 1–200 characters, as the competition requires). Node 22, standard library only — no dependencies.
